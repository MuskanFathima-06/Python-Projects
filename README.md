## Projects

### 1️⃣ BMI Calculator
- A Python script that calculates **Body Mass Index (BMI)** based on user input (height and weight).
- Includes logic to categorize health risk levels (Underweight, Normal, Overweight, Obese).
- Demonstrates **conditional statements, input validation, and basic math operations**.

---

### 2️⃣ Automatic File Sorter
- A utility script that automatically sorts files into folders based on their extensions (e.g., `.pdf`, `.jpg`, `.csv`).
- Helps organize messy directories with just one run.
- Demonstrates **Python automation, file handling, and OS module usage**.

---

### 3️⃣ Web Scraping – Wikipedia
- Extracts information from **Wikipedia pages** using libraries like `requests` and `BeautifulSoup`.
- Cleans and structures the scraped text for analysis or presentation.
- Demonstrates **web scraping fundamentals and HTML parsing**.

---

### 4️⃣ Web Scraping – Flipkart
- Scrapes product details (name, price, ratings) from **Flipkart**.
- Useful for price comparison and market research.
- Demonstrates **e‑commerce scraping, pagination handling, and data extraction**.

---

### 5️⃣ Web Scraping – Crypto API
- Fetches live cryptocurrency data (prices, market cap, volume) using a **Crypto API**.
- Displays structured results for analysis or dashboard integration.
- Demonstrates **API requests, JSON handling, and real‑time data analysis**.
